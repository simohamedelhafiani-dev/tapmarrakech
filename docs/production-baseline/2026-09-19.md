## Important status

This manifest is versioned in GitHub, but it is **not** claimed to be a complete executable reconstruction of production.

The production export proves the existence of objects that are not currently represented by repository migrations, notably employee authentication/session objects and subscription/payment/invoice objects. The full production DDL for those objects must be reconstructed and reviewed before treating a fresh database deployment as reproducible.

No production migration is being executed from this branch.

## Phase 1 rules

- Production remains untouched while migrations are prepared.
- Each migration is tested on a dedicated Supabase test project first.
- One migration at a time.
- Backup before every production change.
- Scanner work precedes rate limiting, which precedes storage hardening.
- Review submission and Google redirect code/database objects are explicitly out of scope.
- Public menu reads remain public.
